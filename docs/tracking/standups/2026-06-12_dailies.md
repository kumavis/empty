### Stage 3 — Design (draft + probes)

- Extracted the oracle verbatim (brace-matching script; first attempt broke
  on destructured-param braces — lesson: match the param parens first).
- Ran six probes against the oracle. **Surprise of the day (P2/P6): a sybil
  ring lifts group allocation 0.256 → 0.758 — but it is numerically
  IDENTICAL to single-account self-trust at every α.** The paper's
  conservation claim holds exactly for honest splits (Δ ≈ 1e−16). This
  settled three design decisions at once: ban self-trust as a game rule,
  balance-vector zero-row fallback, and the Sybil Garden level teaching the
  ring caveat honestly.
- P1 settled α=0.15 default (×1.53 allocation swing from one player's trust
  shift — a strong, legible lever); P5 settled percentage issuance 5–10% so
  comeback arcs fit in 10–15 round levels; P3 settled threshold 1e−9 (cost
  trivial: ≤113 iterations at n≤12).
- Wrote the design doc with progress tracker, architecture (engine/rules/
  views), 6-level campaign, test strategy, worked example (verified against
  the oracle to 5 decimals), drift risks per phase, Stage 0 gate.
- Committed as Stage 3a (commit bb541a5); scaffolding fast-follow 358127c
  (package.json, .gitignore, seeded test utils) and first push of the branch.

### Stage 3 — Critique round (D.2 → D.3)

- Self-critique (lenses P/R/M/S): 9 findings, 4 adopted into the design
  (provisional level numbers, parity-test param discipline, supply
  invariant, serializability test).
- External critique (delegated to an independent agent with oracle access):
  9 findings, **all accepted**. Headline: **levels 1–2 as sketched were
  provably unwinnable** — exhaustive 3¹⁰-strategy search showed the player's
  share decays under every play, and share goals are *invariant to issuance
  rate and round budget* (convex-combination argument), so the planned
  "tune in Phase 4" mitigation could never have fixed them. Lesson for the
  PIR: our own probes validated the mechanism but never adversarially
  probed a *level*; the critic's probes did. Other accepted findings:
  diagonal self-trust smuggled back via the balance-vector fallback (X3 —
  silence subsidy grows with wealth), forecast contract unspecified (X4),
  raw-vs-normalized mirror exploit (X5 — the tutorial was winnable *only*
  through the exploit), negative-control level QA (X6), non-convergence +
  schema validation (X7), goal edge semantics (X8), personalities missing
  from the view contract (X9).
- Design revised to D.3: tutorial goals pivot to absolute-balance targets;
  share/leader goals require a measured reachability ceiling; observation
  contract = row-normalized matrix only; forecast = full pipeline minus
  mint; diagonal-zeroed fallback; level schema validator; canonical naive
  scripts as per-level negative controls (greedy bot included — makes "not
  greedily solvable" measurable).
- **User requirement added mid-design (2026-06-12): web view must run all
  simulation in a Web Worker.** Folded into §3.5: module worker owns
  GameState and imports `src/`; main thread is postMessage + render only.
  Serializability (S3) is now load-bearing for the worker boundary.
- Committed as Stage 3b (commit a07760e).
