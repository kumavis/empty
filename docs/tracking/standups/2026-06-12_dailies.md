### Stage 3 — Design (draft + probes)

- Extracted the oracle verbatim (brace-matching script; first attempt broke
  on destructured-param braces — lesson: match the param parens first).
- Ran six probes against the oracle. **Surprise of the day (P2/P6): a sybil
  ring lifts group allocation 0.256 → 0.758 — but it is numerically
  IDENTICAL to single-account self-trust at every α.** The paper's
  conservation claim holds exactly for honest splits (Δ ≈ 1e−16). This
  settled three design decisions at once: ban self-trust as a game rule,
  balance-vector zero-row fallback, and the Sybil Garden level teaching the
  ring caveat honestly.
- P1 settled α=0.15 default (×1.53 allocation swing from one player's trust
  shift — a strong, legible lever); P5 settled percentage issuance 5–10% so
  comeback arcs fit in 10–15 round levels; P3 settled threshold 1e−9 (cost
  trivial: ≤113 iterations at n≤12).
- Wrote the design doc with progress tracker, architecture (engine/rules/
  views), 6-level campaign, test strategy, worked example (verified against
  the oracle to 5 decimals), drift risks per phase, Stage 0 gate.
